## Blueprint target
US004 requires at least 40 small synthetic JSON fixtures containing ID, category, HTML, literal expected Markdown and literal expected text, with status where applicable. Required coverage includes blocks, inline marks, URLs, code, tables, whitespace, entities and removed content. The hand-reviewed set must include nesting, adjacent block boundaries, Unicode, unsafe targets and malformed HTML. Missing expected fields and duplicate IDs must fail validation. Large boundary cases must be generated by scripts rather than committed as megabyte-scale fixtures.
