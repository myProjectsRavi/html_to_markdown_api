## Blueprint acceptance target
US005 requires exact case-sensitive paths and methods, JSON 404/405 envelopes, route-specific Allow headers, a public health response, and centrally applied `Cache-Control: no-store`, `X-Content-Type-Options: nosniff`, and JSON content type. Wrong case and trailing slash must be 404. HEAD and OPTIONS on known paths must be 405. Unknown paths must remain 404 even when a gateway credential is present. Query values must not appear in response bodies or logs. Conversion routes may use a typed internal placeholder but must not fabricate success.
