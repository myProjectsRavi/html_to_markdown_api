# US010 evidence - Build the bounded parser adapter

Status: IN_PROGRESS

## Source-derived acceptance target
US010 requires parser-event, retained-node, open-depth, attribute-count, attribute-name and attribute-value limits to be enforced during parsing. Exact-boundary and plus-one tests are required for every limit. Skipped subtrees must still consume relevant budgets, malformed long tags must not create unbounded retained structures, parser exceptions must not yield partial success, and application timers must not be presented as synchronous-parser preemption.

## Implementation checkpoint
- Refines `ParserBudget` into independently testable counters for tokenizer events, retained nodes, open depth, per-element attributes, attribute-name Unicode scalars and attribute-value UTF-8 bytes.
- Adds `src/html/parse.ts` around the selected `htmlparser2@12.0.0` callback Parser.
- Attributes are checked from `onattribute` before any application tree node is retained.
- Parsing uses an explicit frame stack rather than recursive application traversal.
- Optional skipped subtrees are represented by bounded stack frames with null retained nodes; their open/text/close/attribute callbacks still consume budgets.
- Limit failures are typed `ParserLimitError`; non-limit parser failures are normalized to `ParserInternalError`.
- The Worker maps parser-limit failures to the fixed `input_too_complex` envelope and unknown parser failures to `internal_error`, with no partial success response.
- No timer or `Promise.race` CPU-preemption claim is introduced.
- Targeted tests exercise actual launch boundaries and adversarial skipped/malformed structures.
