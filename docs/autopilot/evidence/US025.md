## Acceptance evidence

Clean text is rendered directly from the normalized shared tree. Headings and emphasis add no Markdown delimiters. Literal user punctuation including `*` and `<` survives unchanged. `br` emits LF, `hr` creates structure without visible Markdown syntax, nested blocks use stable blank lines, and protected pre/code whitespace and punctuation are retained.

Script/style content is absent through the shared clean tree, and empty or removed-only HTML returns an empty string. A dedicated fixture demonstrates that naive Markdown stripping would corrupt literal punctuation while the direct renderer does not.

Consumer guidance is documented in `docs/decisions/clean-text.md`: clean text is a JSON string for text handling, and browser integrations must use a text sink such as `textContent`, not `innerHTML`.
