# US037 - Complete and validate OpenAPI

Status: DONE

Tested exact branch SHA: `3946aa18dce6769ea04cda915ec697b88976fc89`

## Public specification

- `openapi.yaml` is OpenAPI 3.0.3 for current RapidAPI importer compatibility.
- It defines exactly the three implemented paths: `/health`, `/v1/html/markdown`, and `/v1/html/text`.
- Conversion request shape is closed to the single `html` property and documents the raw JSON and decoded HTML limits.
- All runtime limits from `src/config.ts` are mirrored in `x-limits`.
- The complete runtime validation precedence is mirrored in `x-validation-precedence`.
- Every fixed runtime error from `src/errors.ts` is mirrored in `x-error-catalog`.
- Router-only 404/405 behavior is described separately in `x-router-errors`.
- Success and error response schemas/examples are included.
- No URL-fetch endpoint or hidden URL option exists.

## Authentication boundary

The public contract separates RapidAPI customer authentication from the private gateway-to-origin credential:

- customer subscription header: `X-RapidAPI-Key`;
- customer routing header: `X-RapidAPI-Host`;
- private origin credential exposure: false.

The public specification does not contain `X-RapidAPI-Proxy-Secret` and does not instruct marketplace clients to send the Worker's private origin credential.

Decision record: `docs/decisions/US037_OPENAPI.md`.
